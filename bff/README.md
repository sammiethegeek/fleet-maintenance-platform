# Smart Fleet Maintenance BFF

Minimal Express/TypeScript Backend-for-Frontend for the Angular demo.

## Run

```bash
npm install
npm run dev
```

Defaults:

- BFF URL: `http://localhost:3000`
- Spring Boot backend: `http://localhost:8080/api`
- Angular CORS origin: `http://localhost:4200`

Override backend URL:

```bash
BACKEND_BASE_URL=http://localhost:8080/api npm run dev
```

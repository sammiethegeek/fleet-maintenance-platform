# Smart Fleet Maintenance Frontend

Minimal Angular 17 demo for the Smart Fleet Maintenance workflow.

## Run

```bash
npm install
npm start
```

The app runs at `http://localhost:4200` and calls the BFF at `http://localhost:3000/api`.

## Demo Users

- `coordinator` / `coordinator123`
- `provider` / `provider123`

## Screens

- `/login`
- `/dashboard`
- `/request-form`
- `/inspection-form/:id`
- `/decision-form/:id`
